# 七阶段工作台集成（2026-10-29）

目标是同一研究任务承载七个业务阶段。七个页面可用不等于七阶段真实业务闭环；G1—G4 守卫、正式版本与公开问卷分别验收。

| 阶段 | 已接入的页面操作 | 服务边界 |
| --- | --- | --- |
| 赛事理解 | 原有编辑/保存；当前智能体项目的研究简报预览下载 | G1 状态不自动推进正式阶段 |
| 选题分析 | 原有编辑/保存；研究问题预览下载 | 不自动覆盖人工选题 |
| 研究方案 | 原有编辑/保存；调查方案预览下载 | 不自动采用模型建议 |
| 问卷设计与预测试 | 原编辑器；同一会话消息、G2 表单/确认及问卷目录产物 | 服务要求先通过 G1，团队提供题项；未证实 G2 通过前保持待验 |
| 正式调查 | 发布准备本机编辑保存、当前问卷填写预览 | 采集服务未交付；预览不存答卷；无发布链接、回收数或停止成功 |
| 数据分析 | 同任务既有沙箱组件，CSV/XLSX 上传、真实统计、保存结果与恢复；G3 产物 | 本机沙箱独立于 G3；G3 仅 CSV/TSV，需要 G2 和团队分析计划 |
| 报告与答辩 | 人工正文、引用、答辩草稿本机保存与纯文本预览；同会话 G4 目录产物 | G4 是骨架与辅助材料，正式版本保存/导出仍待接入 |

## 数据与代码

- `src/types/research-contracts.ts`：`CollectionDraft`、`ReportDraft`，归属同一 `LocalResearchTask`。
- `src/utils/researchDrafts.ts`：缺失新增字段的旧草稿按空值读取；存在但格式损坏时拒绝覆盖。完整研究允许沙箱引用，已有问卷入口继续拒绝分析引用。
- `src/stores/research.ts`：同任务本机保存、异步沙箱结果按捕获的任务编号写回；不跟随当前页面切换写到另一任务。
- `src/views/ResearchWorkspaceView.vue`：挂载七阶段及同一智能体会话；阶段浏览只修改 `viewedPhase`。
- `src/utils/researchStageArtifacts.ts`：项目编号按路径段精确匹配，筛选展示；传给后端的原路径不改写，不凭文件名判定阶段通过。
- `src/views/research/ResearchLaterStageHost.vue`：调查准备、填写预览、报告编辑容器；无额外后端和自动采纳。
- `src/views/research/ResearchAgentPanel.vue`：当前阶段结果、同会话原运行表单续跑，按阶段附加本机材料；文件元信息明确不是智能体上传引用。
