# 市调演真首版范围与任务状态

更新：2026-10-27。用于持续派工和验收；目标范围不表示功能已经交付。以用户最新确认的业务顺序和平台内匿名调查需求为准，覆盖历史文档中相冲突的安排。

## 1. 首版要交付什么

让用户从赛事资料出发，逐步完成研究设计、问卷与真实调查、数据分析、报告与答辩；每一步保留来源、未知项和版本，由用户确认采用。已有问卷和已有答卷是独立快捷入口，不补记没有实际发生的前期工作。

公共接口和后端能力可以提前准备；真实接口一到就联调。功能按业务顺序验收，不要求等前一阶段所有后台开发结束才开始下一项前端工作。

需求说明用户想完成什么；任务说明我们具体改哪一部分；验收标准说明用什么操作和结果判断它做完了。三者分开，避免把页面占位或代码提交当成功能可用。

## 2. 状态怎么读

- **本机已验**：有历史真实操作证据，但不代表正式业务服务器或团队部署完成。
- **前端基础已验**：任务状态、类型、挂载或合成样例已验证，不代表正式编辑组件已交付。
- **待组件**：本消费目录还没有实际交付组件，不能只据计划宣布可用。
- **待接口**：没有真实服务地址、请求/响应与错误约定；不能猜 URL 或显示服务器保存成功。
- **范围预览**：只有阶段导航和说明，业务功能尚未验收。

## 5. 组件交付时必须拿到什么

1. 仓库地址、分支与提交号；或者实际可读的本地交付目录及版本说明。
2. 组件文件与必要子组件、局部样式、类型/依赖清单，不能只复制单个 Vue 文件就假定完整。
3. props/events 用法与空/正常/错误/只读样例；已有组件接口不同则在接入层对齐，不要求同事推倒重写。
4. 同事已测/未测内容。组件自测是交接依据，挂进真实工作台后仍需验证本机保存和任务恢复。
