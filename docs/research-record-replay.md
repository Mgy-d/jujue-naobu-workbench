# 研究过程保存与演示

## 使用方式

1. 等本轮回复结束后，点击工作台顶部“保存成果记录”（未接入数据库时显示“保存本次记录”）。
2. 保存结束后点击“记录复现”或“本机复现”。
3. 演示在同一工作台中打开；底部可播放、暂停、上一步、下一步、从头演示或按研究环节跳转。步数按输入与后续回复的操作回合、表单和明确阶段变化计算，连续回复不再逐句计步。
4. 走到历史表单时弹出当时的填写内容；控件只读，“演示提交并继续”只推进本机播放。没有保存原答案的表单不会补造答案。
5. 右侧展示保存版本的相关成果，可以预览和下载。退出演示回到原研究，不改变输入草稿或原会话状态。

## 保存范围

- 新记录 version=2，每次使用新 ID 保存，不覆盖先前版本。旧 version=1 记录仍可读取，在版本列表中保留。
- 对话优先补读当前研究的转录，并与本机已读消息合并；接口不可用时明确列出历史范围缺口。
- 新提交的表单在请求发出时记录表单结构、答案及对应用户消息 ID。旧表单仅从原工具调用恢复结构；答案只采用唯一且字段校验通过的结构化结果，超时、重复或不明结果不当作已确认答案。
- 完整文件字节保存在本浏览器 IndexedDB；网络及现有研究存储接口可用时，同时上传文件副本与演示记录到公司数据库。界面分别报告本机保存与数据库同步结果。
- 每个演示版本使用保存时的成果文件；没有早期文件版本时不能还原成当时的内容。不会在播放过程中向智能体重新生成或读取成果。
- 文件补读失败、超出单件 20MB 或没有原文件副本时记录缺口，不使用其他研究的文件代替。

## 隔离和限制

- 演示组件没有研究运行、审核提交、正式答卷收集或统计执行入口。问卷展示复用现有预览，历史模式隐藏发布入口。
- 演示期间暂停原页面后台核对；账号、任务或版本变化后停止旧预览，二进制预览复用现有组件，通过已保存文件读取函数提供字节。
- 本机版本只属于当前浏览器和访问地址；换浏览器/端口或清理站点数据可能不可见。跨电脑需要对应版本及其文件已成功同步公司数据库。
- 本轮仅完成本机合成验证；公司网络不可用，真实云端转录补读、文件同步及跨电脑读取仍需联调。

## 成果展示

报告正文的 Word、PDF 与答辩 PPT 优先显示，不因放在内部状态目录下的交付区而被归为过程文件。过程检查、输入模板与代码仍按原规则收起。同目录同名图片的不同格式使用一张卡片切换；不同目录的同名图片保留来源区别，不依据文件大小或时间擅自判定最终版本。
