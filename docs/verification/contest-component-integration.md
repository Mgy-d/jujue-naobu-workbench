## 代码阅读顺序

1. `ResearchWorkspaceView.vue` 选择任务并将 draft/context 交给宿主。
2. `CompetitionUnderstandingHost.vue` 自动发现正式编辑器，绑定更新和保存事件。
3. `ResearchDesignEditor.vue` 以 props 显示内容，通过 update-draft 返回整份新草稿；不直接写 localStorage。
4. `stores/research.ts` 校验 localTaskId/revision 并更新任务；本机保存交给 `utils/researchDrafts.ts`。
5. 刷新时读取本机任务目录，再传回组件。正式服务器保存仍要等待 BA 真实端点和固定版本响应。
