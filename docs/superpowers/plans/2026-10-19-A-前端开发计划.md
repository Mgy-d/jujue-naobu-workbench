# A 方案前端整合 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**状态：** 用户要求编制的待评审计划，不代表已经批准 A 或开始实现。两案只执行其一；执行方式由用户另行选择，本次未启动子代理。

**Goal:** 在单一 Vue 工程中，用数模演易式整站和工作台布局承载拒绝脑补完整市调流程。

**Architecture:** 页面和组件统一 Vue 化；engine 管纯业务规则，Pinia 引用唯一项目记录，Repository 管事务化持久化，RunGateway 管明确的演示或真实事件。A 工作台使用顶部阶段导航、可收起项目切换和右侧待确认/成果/过程区域。

**Tech Stack:** Vue 3、TypeScript、Vite、Pinia、Vue Router、Element Plus、Markdown-it；Vitest、Vue Test Utils、Playwright。pnpm 精确锁定依赖；版本及 Node 24 兼容性由 A-F01 实测冻结，不照搬旧依赖结论。

**Spec:** [A 方案](../specs/2026-10-19-A-全站数模外壳与市调内核.md)、[共同契约](../../frontend/shared-contracts.md)、[视觉约束](../../../DESIGN.md)。执行者先读这三份及来源指纹。

## Global Constraints

- 品牌名称固定为“拒绝脑补”，全站采用雾蓝。
- 七阶段业务规则来自原型归档，数学建模逐问求解流程不进入市调状态机。
- 对话卡、预览、版本列表、全屏和下载绑定同一 projectId + artifactId + versionId。
- 草稿、已保存待确认、已采用、历史与需重新核对分开表示。
- 本轮前端迁移不以真实模型、通用文件解析、Python 服务或云协作为完成前提。
- 归档原型、D:/scdc-develop 和作者日常浏览器数据保持不变。
- 真实服务失败不得静默切换为模拟成功。
- 本次文档没有授权开始产品代码实施。

关键单测断言示例（纳入F02/F07/F08；不是本次运行结果）：

```ts
const p = createProject({ title: '虚构测试', mode: 'custom' })
p.stage = 3
expect(canAdvance(p).ok).toBe(false)
expect(p.stage).toBe(3)

const r = deriveObservation([
  { id: 'a', score: '5' }, { id: 'b', score: '' },
  { id: 'c', score: '2' }, { id: 'd', score: null },
], 'score', { threshold: 4, limit: 4 })
expect(r).toMatchObject({ selected: 1, valid: 2, percent: 50 })

const text = '同句\n同句'
const proposal = proposeRevision({ before: text, replacement: '新句',
  selectionStart: 3, selectionEnd: 5, baseSignature: textSignature(text) })
expect(applyRevision(text, proposal)).toEqual({ ok: true, text: '同句\n新句' })
expect(applyRevision(text + '已改', proposal)).toEqual({ ok: false, reason: 'stale' })
```
